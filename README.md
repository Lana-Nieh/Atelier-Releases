# Atelier

Atelier 是一款本地素材管理器。把图片、视频和 PDF 收进同一个素材库，用文件夹、标签和备注整理。素材和整理记录都保存在自己的电脑上。

## 当前下载 · Atelier 1.0.0

**[下载 Atelier 1.0.0（macOS · Apple 芯片 · DMG）](https://github.com/Lana-Nieh/Atelier-Releases/releases/download/v1.0.0/Atelier-1.0.0-macOS-arm64.dmg)**

适用于搭载 M 系列芯片的 Mac。打开磁盘映像，将 Atelier 拖到「应用程序」，再从那里启动。本版采用本机临时签名，未经 Apple 公证，首次打开时 macOS 可能提示无法验证开发者。

在工作区按 ⌘V 即可收藏剪贴板里的图片。你也可以用 Chrome 插件采集网页图片，把参考图并排比较，或从视频中标记一帧并保存为 PNG。

[查看 1.0.0 发布说明与文件校验值](https://github.com/Lana-Nieh/Atelier-Releases/releases/tag/v1.0.0)

## 开发中 · Atelier 2.0 网页参考板

下一版将支持直接粘贴网页链接。Atelier 会保存整页截图，提取标题，并从正文生成摘要。卡片显示首屏预览，点开就能阅读长截图。

你可以拖动卡片排序、按主题分区，并给每个网页写下收藏理由。整理好后，开启只读链接，就能把整块参考板发给同事。对方用浏览器即可查看；分享时需要保持 Atelier 运行并联网。
